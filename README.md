
In this case, I aimed to represent the scenario of an airline company that offers a customer loyalty program consisting of a card to accumulate miles, which can also be converted into money to pay for future trips.  
The process begins with the extraction and modeling of data to create a star schema model, using SQL to verify the data and check the transformations needed for the database to be fully functional.  
Then, using PANDAS in Python, the DataFrame is analyzed in greater depth to identify the metrics that will be used to generate a report.  
This report will help interpret the information provided by the data, and the resulting dashboard can be used in a presentation to study possible strategies.  
By identifying user behavior, these strategies aim to increase the number of customers using the system, ultimately generating greater revenue for the airline.
